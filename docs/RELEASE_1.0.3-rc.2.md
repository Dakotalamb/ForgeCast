# FDGCast 1.0.3-rc.2 — Combined Activity Feed

Includes the TikTok LIVE chat and events preview from rc.1. Renames Combined Events
to **Combined Activity Feed**, and the OBS dock to **FDGCast Combined Activity Feed**.
Each audience activity card shows a local platform icon alongside its type, with
platform and channel text retained for clarity. Existing dock IDs, positions and
activity category settings are preserved. Unknown platform values receive no
misleading icon or remote image URL. Icons reuse existing local assets/rendering.

Connect a public LIVE TikTok username to read chat and activity without sending
video from FDGCast. The account must still be LIVE through a phone, LIVE Studio
or another encoder. Follow/gift/subscription notifications and grouped likes/shares
remain experimental, receive-only and subject to TikTok/signing-service availability.
Use Combined Activity Feed → Event categories and tests to select categories.

Close OBS and Companion before installing. This is a preview; stable remains 1.0.2.
Real TikTok LIVE delivery remains an operator test.
